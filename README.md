# SDR Maestro

Bluetooth HID controller for Software Defined Radio applications.

## Hardware

- ESP32-S3 N16R8
- Five rotary encoders
- Five encoder push buttons

## Software

- Arduino IDE 2.x
- ESP32 Arduino Core 3.3.11

## Architecture

- App
- Config
- Version
- Logger
- Queue
- EncoderManager
- ButtonManager
- ProfileManager
- StorageManager
- ActionManager
- HIDManager
- OpenWebRX Profile
