# SDR-Maestro

Bluetooth HID controller for SDR applications.

## Hardware

- ESP32-S3 N16R8
- Incremental rotary encoder
- Encoder push button

## Software

- Arduino IDE 2.x
- ESP32 Arduino Core 3.3.11

## Architecture

- App
- Config
- Version
- Logger
- EncoderManager
- ButtonManager
- ActionManager
- HIDManager
- ProfileManager
- StorageManager
- OpenWebRX Profile
- Queue
- Events
- Types
